01 About the Application

PDF Viewer, Reader & Editor is a mobile document management application designed to help users view, read, edit, organize, convert, compress and manage PDF documents directly on their devices.

The Application provides features including:

  • PDF viewing, reading and navigation.
  • PDF annotations, highlighting, drawing and comments.
  • Adding text, images, stamps and visual signatures.
  • Merging, splitting, rotating, extracting and organizing PDF pages.
  • Converting images, text and other supported formats into PDFs.
  • Converting PDFs into supported image formats.
  • PDF compression and document repair.
  • Password protection and removal of passwords from eligible PDF files.
  • Filling interactive PDF forms.
  • Adding headers, footers, watermarks and page numbers.

Features may be updated, modified, added or discontinued from time to time.
